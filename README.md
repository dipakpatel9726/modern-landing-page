# 🌐 Responsive Business Website

A modern and fully responsive business website built using **HTML** and **CSS**.
This project includes a clean UI design with essential sections like Hero, About, Services, and Contact.

---

## 🚀 Features

* ✅ Responsive Design (Mobile Friendly)
* ✅ Clean and Modern UI
* ✅ Navigation Bar with Smooth Layout
* ✅ Hero Section with Call-to-Action Buttons
* ✅ About Section with Image & Content
* ✅ Services Section with Cards
* ✅ Contact Form UI
* ✅ Footer with Quick Links

---

## 🛠️ Built With

* HTML5
* CSS3 (Flexbox & Layout Styling)
